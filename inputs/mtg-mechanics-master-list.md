# Master MTG Mechanics List — October 2026

This is a comprehensive inventory of Magic: The Gathering mechanics based on MTG Wiki's September 25, 2026 (*Reality Fracture*) Comprehensive Rules snapshot. It includes the three official mechanic classes plus the wiki's supplementary classifications: additional rules, digital-only mechanics, miscellaneous mechanics, Acorn mechanics, playtest mechanics, unreleased mechanics, and former mechanics.

Use this as the **master taxonomy**. For a public compendium, keep official, tournament-legal mechanics separate from Acorn, digital-only, playtest, unreleased, and former content.

# Data-model recommendations

## Required fields

For every entry, store:

| Field | Purpose |
|---|---|
| `slug` | Stable identifier |
| `canonical_name` | Display name |
| `category` | One of the categories above |
| `status` | Active, acorn, digital-only, playtest, unreleased, former, deprecated |
| `rules_reference` | CR number, if applicable |
| `official` | Boolean; true only for CR-defined mechanics |
| `tournament_legal` | Boolean; false for Acorn, most playtest, and unreleased material |
| `color_pie` | Curated Rosewater/color-pie classification |
| `example_cards` | Scryfall card references |
| `related_mechanics` | Cross-links |
| `aliases` | Player terms and spelling variants |
| `source` | CR, MTG Wiki, Scryfall, official article |
| `last_verified_at` | Verification timestamp |
| `rules_version` | Rules snapshot used |

## Recommended category values

- `keyword_ability`

- `ability_word`
- `acorn_ability_word`
- `additional_rules_concept`
- `digital_only_mechanic`
- `miscellaneous_mechanic`
- `acorn_mechanic`
- `playtest_mechanic`
- `unreleased_mechanic`
- `former_mechanic`

## Publication rules

1. Publish `keyword_ability`, `keyword_action`, and `ability_word` entries as the primary mechanics compendium.
2. Publish `additional_rules_concept` entries in a separate “Rules & Frameworks” section.
3. Publish `miscellaneous_mechanic` entries only with a clear disclaimer that they may be slang, effect families, or non-keyword mechanics.
4. Exclude `acorn_*`, `digital_only_*`, `playtest_*`, and `unreleased_*` from tournament-focused searches by default.
5. Keep `former_mechanic` entries searchable for historical research, but mark them clearly as obsolete.

# Deduplication warnings

Several names appear in more than one wiki category. Do **not** create duplicate records blindly. Examples:

- `Die` appears as an additional rules concept and a miscellaneous mechanic.
- `Energy`, `Enter`, `Expend`, `Hand size`, `Intrinsic ability`, `Mana value`, `Starting player`, and `Spellbook` appear in multiple supplementary categories.
- `Best in show`, `Gear up`, and `Gotcha` appear both as Acorn ability words and Acorn mechanics.
- `Rampage` appears both as an official keyword ability and an Acorn mechanic name.
- `City's blessing` is a state tied to the `Ascend` keyword ability, not an independent keyword.
- `Speed` / `Max speed` and `Start Your Engines!` should be modeled as one mechanic family with related states.
- `Day and night`, `Daybound and Nightbound`, and related transform mechanics should cross-link rather than duplicate.

Use a canonical `slug` plus an `aliases` table, and assign one primary category per canonical record.
