RED-TEAM FINDINGS RESOLVED
1. Ordinary o: search omits reminder text. New literal searches use fo: and revalidated witnesses to match the imported Oracle text.
2. A more complex Counter regex was ignored by Scryfall with HTTP 200 plus warnings. The candidate failed membership tests and was rejected. A simpler verified spell/ability expression replaces it; runtime now rejects warning-bearing searches.
3. New recipe IDs initially conflicted with the existing Clipboard ID grammar. IDs now use its existing keyword-index prefix; Clipboard code was not changed.
4. Counter noun uses, name/flavor-only mentions, cross-face concatenation, metadata/text double counting, malformed/missing keywords, unsupported query mutations, mismatched sources, and absent rules were challenged in tests.

CONFIDENCE AND LIMITS
High confidence in the tested additive behavior, source attribution, preservation and manual query boundaries. No numeric probability is claimed.
No claim of exhaustive semantic recall: wording recognizers intentionally omit implicit actions and unreviewed variants. For example, Counter does not infer the action from every use of countered; Harness currently matches the verified The Soul Stone wording. Provider catalogs themselves are not a comprehensive list of all Magic concepts or future releases.
Published Star Trek labels Assimilate and Face a dilemma are sourced to Wizards preview material. This does not certify every unrevealed Star Trek mechanic. Non-Commander, digital, playtest and preview cards can be inspected after import but can correctly yield zero Commander discovery results.
